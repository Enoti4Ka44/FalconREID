# FALCON·ReID — карта возможностей системы

## Поиск и анализ
| № | Фишка | Где | Как |
|---|---|---|---|
| 1 | Мульти-запрос (1–5 снимков, усреднение признака) | Консоль → Запрос | чипы файлов, `+` |
| 2 | Авто-детекция ТС: сервис сам подсвечивает машины, клик — выбор (YOLOv8n, 6.5 МБ); свою рамку можно обвести мышью | превью запроса | клик по рамке |
| 3 | Умный слайдер порога: гистограмма близостей + живые F1/TNR | панель Запрос | двигать τ |
| 4 | Пресеты порога: Строгий (TNR≥0.9) / Баланс / Чувствительный (recall≥0.9) | под слайдером | клик |
| 5 | Карта перемещений по восстановленным локациям | под кандидатами | автоматически |
| 6 | Матрица попарных сходств кандидатов (кто — одна машина) | кнопка «Матрица сходств» | клик |
| 7 | Дуэль-сравнение: шторка фото↔attention + синхронная зум-лупа | клик по кандидату / `C` | колесо — лупа |
| 8 | Досье ТС: появления в галерее, метки «та же сцена» | «досье» / `D` | клик |
| 9 | Близнецы: похожие, но отклонённые порогом | секция внизу | раскрыть |
| 10 | Объяснимость: attention запроса и каждого кандидата | `E` / дуэль | — |

## Работа оператора
| № | Фишка | Где |
|---|---|---|
| 11 | Режим оператора: ←→ навигация, Y/N вердикты, журнал с CSV | `J` |
| 12 | Кейсы расследований: имя, автоприкрепление поисков, экспорт JSON | чип «кейс» |
| 13 | История поисков с восстановлением в один клик | `H` |
| 14 | Вочлист «на контроле»: цели + алерты при каждом новом поиске | чип «контроль» / `W` |
| 15 | Пакетный поиск: до 30 запросов таблицей + CSV | кнопка «Пакетный поиск» |

## Система
| № | Фишка |
|---|---|
| 16 | Вкладка «Архив»: вся галерея, фильтр по локациям, A/B-сравнение любых двух снимков |
| 17 | Вкладка «Статистика»: аудит сервиса (запросы/латентность/отказы/алерты), загрузка локаций, «повторные появления» — машины, замеченные в 2+ локациях |
| 18 | Командная палитра Ctrl+K со всеми действиями |
| 19 | Обучение-тур при первом входе + справка `?` |
| 20 | PDF-отчёт по кейсу · шаринг поиска ссылкой · Ctrl+V вставка из буфера · PWA (устанавливается как приложение) |
