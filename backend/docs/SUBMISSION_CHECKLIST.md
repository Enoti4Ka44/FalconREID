## Ссылки для платформы (п. 13)

1. **Git-репозиторий** — запушить `solution/` на GitHub/GitLab (код открыт,
   не обфусцирован). Большие файлы (`models/*.pt`, `*.npz`) — через Git LFS
   или в релиз-ассеты.
2. **Файл презентации** — `docs/ЛЦТ2026_ФальконТех_презентация.pptx`
   (перед сдачей: вписать название команды на титуле и слайде «Команда»).
3. **Работающий прототип** — варианты:
   - VPS с GPU: `DATA_DIR=/data docker compose up -d` → публичный URL;
   - VPS без GPU: тот же compose, работает на CPU (инференс ~1–2 с/запрос);
   - демо-ссылка с автозапуском поиска: `http://<host>:8000/?demo=<image_id>&x=..&y=..&w=..&h=..`
4. **Сопроводительная документация** — `docs/SOLUTION.md` (можно
   конвертировать в PDF: открыть в браузере → печать в PDF).
