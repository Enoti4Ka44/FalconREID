# FALCON ReID — API Reference

> FastAPI-сервис формирования цифрового признака ТС для сопоставления снимков одного автомобиля из разных локаций без использования госномера.
>
> OpenAPI: `GET /docs` (Swagger UI), `GET /openapi.json`

---

## Архитектура

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  Фронтенд   │────▶│  FastAPI app │────▶│  ReIDEngine  │
│  (static/)  │     │  (app.py)    │     │ (engine.py)  │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                                │
                                     ┌──────────┼──────────┐
                                     │          │          │
                                  Модели    FAISS Index   Галерея
                                (ensemble)  (поиск)    (npz+кропы)
```

**Стек:** FastAPI + PyTorch + timm (DINOv2/ConvNeXt) + FAISS + YOLOv8n  
**Модель:** Ансамбль из N моделей (ViT-B/14, ViT-L/14, ConvNeXt-base, DINOv3), взвешенная конкатенация L2-нормированных эмбеддингов  
**Постобработка:** alphaQE (расширение запроса), DBA (расширение галереи), косинусный порог отказа

### `POST /api/search`

**Основной эндпоинт.** Поиск ТС по изображению(ям) в галерее.

**Запрос:** `multipart/form-data`

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `files` | File[] (1-5 шт) | Да | Снимки ТС. BBox применяется к ПЕРВОМУ, остальные — готовые кропы |
| `x` | int | Нет | X верхнего угла BBox (для первого снимка) |
| `y` | int | Нет | Y верхнего угла BBox |
| `w` | int | Нет | Ширина BBox |
| `h` | int | Нет | Высота BBox |
| `top_k` | int | Нет (10) | Количество кандидатов |
| `threshold` | float | Нет | Переопределить порог отказа |

**Ответ:** `SearchResponse`
```json
{
  "query_embedding_dim": 1536,
  "inference_ms": 45.2,
  "threshold": 0.302,
  "refused": false,
  "message": "Принято кандидатов: 3",
  "n_query_images": 1,
  "sim_max": 0.8912,
  "sim_hist": {
    "counts": [0, 0, 5, ...],
    "edges": [-0.2, -0.175, ...]
  },
  "candidates": [
    {
      "gallery_id": "abc123",
      "confidence": 0.8912,
      "accepted": true,
      "camera_group": 3
    }
  ],
  "watchlist_alerts": [
    {
      "id": "w123456",
      "name": "Подозрительный",
      "gallery_id": "xyz789",
      "confidence": 0.85
    }
  ]
}
```

**Логика:**
1. Декодирует изображения, при необходимости кропает по BBox (с 6% запасом)
2. Извлекает эмбеддинги каждой модели ансамбля, конкатенирует с весами
3. Усредняет эмбеддинги мульти-запроса, L2-нормирует
4. AlphaQE: расширяет запрос топ-k ближайшими из галереи
5. FAISS поиск top_k ближайших
6. Считает гистограмму всех близостей (для слайдера)
7. Проверяет вочлист — если запрос совпал с «цельми», поднимает алерт
8. Логирует в аудит (последние 2000 запросов в памяти)

**Ошибки:** `400` если >5 файлов или невалидный BBox.

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|

**Ответ:**

```json
}
```

**Использование:** внешние системы, кастомные пайплайны, отладка.

### `POST /api/detect`

Детекция транспортных средств на кадре (YOLOv8n, 6.5 МБ). UX-подсказка: сервис сам подсвечивает машины, оператор кликает нужную.

**Запрос:** `multipart/form-data`

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `file` | File | Да | Полный кадр (фото с камеры) |

**Ответ:**
```json
{
  "width": 1920,
  "height": 1080,
  "boxes": [
    {
      "x": 450,
      "y": 300,
      "w": 200,
      "h": 150,
      "score": 0.92,
      "cls": "car"
    }
  ]
}
```

**Классы COCO:** `car`, `motorcycle`, `bus`, `truck` (классы 2, 3, 5, 7)  
**Порог:** conf >= 0.28, imgsz=1280  
**Сортировка:** по площади BBox (убывание), максимум 20 результатов.

### `POST /api/explain`

Интерпретируемость: карта внимания ViT для запроса.

**Запрос:** `multipart/form-data` (те же поля, что `/api/embed`)

**Ответ:**
```json
{
  "image_base64": "iVBORw0KGgo..."
}
```

**Логика:** перехватывает последний attention-блок ViT, извлекает CLS→patch attention, усредняет по головам, накладывает heatmap (inferno colormap, 45% прозрачность) на кроп.

### `GET /api/gallery/{image_id}/similar`

«Досье ТС»: ближайшие появления объекта галереи внутри самой галереи.

**Параметры:** `top_k` (int, по умолчанию 12)

**Ответ:**
```json
{
  "gallery_id": "abc123",
  "camera_group": 3,
  "neighbors": [
    {
      "gallery_id": "def456",
      "confidence": 0.92,
      "camera_group": 5,
      "same_scene": false
    }
  ]
}
```

**Поле `same_scene`:** `true` если сосед в той же камере-группе (внутри сцены).

### `GET /api/stats/tracks`

«Треки»: машины, повторно замеченные в двух и более локациях (связные компоненты галереи по близости признака cos >= 0.65).

**Ответ:**
```json
{
  "threshold": 0.65,
  "n_tracks": 42,
  "tracks": [
    {
      "size": 5,
      "locations": [0, 3, 7],
      "items": [

        {"gallery_id": "def", "camera_group": 3}
      ]
    }
  ]
}
```

**Кэшируется** после первого вызова. Максимум 60 треков в ответе, максимум 8 элементов на трек.

## Модель данных

### SearchResult (элемент кандидата)
| Поле | Тип | Описание |
|------|-----|----------|
| `gallery_id` | string | ID объекта в галерее |
| `confidence` | float | Косинусная близость (0..1) |
| `accepted` | bool | Принят ли (>= threshold) |
| `camera_group` | int | Камера-группа (локация) |

### Камеры-группы
Камеры-группы (локации) восстанавливаются по фону кадра (`src/camera_infer.py`): дескриптор фона (уменьшенный кадр с замаскированным BBox) кластеризуется по порогу похожести. Используются для:
- Фильтрации в архиве (`/api/gallery/list?group=N`)
- Статистики локаций (`/api/stats/locations`)
- Треков по локациям (`/api/stats/tracks`)
- Маршрутизации в досье (`/api/gallery/{id}/similar`)

## Движок (ReIDEngine)

Ядро сервиса — `service/engine.py`. Все эндпоинты обращаются к нему.

### Инициализация
- Загружает ансамбль моделей из `models/ensemble.json` (или fallback на MODEL_PATH)
- Загружает FAISS-индекс галереи из `models/gallery_index.npz`
- Читает параметры постобработки из `models/postproc.json`
- Порог отказа: env `REFUSAL_THRESHOLD` > `models/threshold.json` > 0.302

### Ключевые методы

| Метод | Что делает |
|-------|-----------|
| `embed(img)` | Извлекает L2-нормированный эмбеддинг (ансамбль N моделей, взвешенная конкатенация) |
| `search(emb, top_k, threshold)` | FAISS поиск + alphaQE + гистограмма близостей |
| `crop_bbox(img, x, y, w, h)` | Кроп с 6% запасом (как при обучении) |
| `attention_map(img)` | Карта внимания последнего блока ViT (CLS→patch) |
| `similar_in_gallery(image_id)` | Ближайшие соседи объекта в галерее |
| `location_stats()` | Счётчик снимков по камерам-группам |
| `gallery_page(group, offset, limit)` | Постраничный архив галереи |
| `cross_location_tracks()` | Связные компоненты по cos>=0.65, ≥2 локации |
| `pair_matrix(ids)` | Попарная матрица косинусных близостей |
| `vector_of(gallery_id)` | Эмбеддинг объекта галереи (или None) |
| `thumb_path(image_id)` | Путь к кропу (или None) |
| `gallery_crop(image_id)` | PIL-кроп для attention-карты |

## Сценарии использования для веб-сервиса

### Текущий функционал (только нейронка)
1. **Поиск ТС** — загрузка фото → получение кандидатов из галереи
2. **Детекция** — подсказка BBox для оператора
3. **Интерпретируемость** — attention-карты
4. **Мониторинг** — статистика, треки, аудит
5. **Вочлист** — контроль конкретных ТС

### Потенциал для расширения (веб-сервис)
1. **Аутентификация** — нет авторизации, роли, API-ключи
2. **Мультитенантность** — нет изоляции данных по пользователям/организациям
3. **База данных** — всё в файлах (npz, json), нет персистентного хранилища
4. **Очередь задач** — синхронный инференс, нет фоновой обработки
5. **Уведомления** — вочлист только в RAM, нет push/email/SMS
6. **Интеграции** — нет webhook, нет внешних API для смежных систем
7. **Аналитика** — простой аудит в RAM, нет постоянного логирования
8. **Админка** — нет управления моделями, галереей, пользователями
9. **Batch-загрузка** — нет массового импорта фото/видео
10. **Видео** — нет обработки видеопотоков
