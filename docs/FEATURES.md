# FALCON ReID — карта возможностей системы

## Веб-интерфейс (React, `frontend/`)

| № | Возможность | Где |
|---|---|---|
| 1 | Регистрация и вход по JWT; защищённые страницы возвращают на исходный маршрут после входа | `/auth` |
| 2 | Поиск по 1–5 фотографиям одного ТС (признак усредняется) | `/app` |
| 3 | Выбор точного кадра из видео прямо в браузере (ffmpeg.wasm): таймлайн, шаг по кадрам | `/app` → видео |
| 4 | Ручное кадрирование области автомобиля с пресетами пропорций и отменой | `/app` |
| 5 | Параметры поиска: top-N (5/10/20/50) и порог отказа (авто — серверный τ, или ручной) | `/app` |
| 6 | Результат: совпадение или отказ, уверенность, камера-группа, время инференса, размерность | `/app` |
| 7 | Карта внимания модели и сравнение запроса с кандидатом «шторкой» | `/app` → «Внимание модели» / «Сравнить» |
| 8 | Гистограмма близостей ко всей галерее с отметкой порога | `/app` |
| 9 | Экспорт результата поиска в JSON и CSV (для Excel) | `/app` → «JSON» / «CSV» |
| 10 | Галерея: последовательная загрузка, фильтры (ID, камера, размер, ориентация), сортировка, полный кадр | `/gallery` |
| 11 | Аналитика: объекты и камеры-группы, межкамерные треки, активность и время поиска, личная статистика и история | `/analytics` |
| 12 | Лендинг продукта со сценариями применения | `/` |

## API (`backend/service/`, Swagger — `/docs`)

| Группа | Методы |
|---|---|
| Поиск | `POST /api/search` (1–5 снимков, BBox, top-N, порог, алерты watchlist, гистограмма) · `POST /api/batch_search` · `POST /api/embed` · `POST /api/explain` |
| Галерея | `GET /api/gallery/list` · `/{id}/thumb` · `/{id}/frame` · `/{id}/similar` («досье») · `/{id}/attention` (если карты предрассчитаны) |
| Аналитика | `GET /api/stats/locations` · `/tracks` · `/usage` · `/my` · `/my/history` |
| Watchlist | `GET/POST/DELETE /api/watchlist` · `POST /api/pair_matrix` · `GET /api/compare` |
| Доступ | `POST /api/auth/register` · `/login` · `GET/POST/DELETE /api/auth/keys` (API-ключи для интеграций) |
| Служебное | `GET /api/health` · `GET /api/val_curves` · `POST /api/detect` (подсказка рамок YOLOv8n) |

## Интеграции

* REST с `X-API-Key` для machine-to-machine.
* MCP-сервер `backend/mcp_server.py` — доступ AI-агентов к поиску, галерее и
  статистике (`backend/MCP_guide.md`).
